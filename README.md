# my-personal-portfolio website


Project Description

This project involves designing and developing a personal portfolio website using HTML and CSS. The website presents my personal information, educational background, technical skills, projects and contact information.

The website uses a modern and luxurious design with black, royal purple and white colours.

Project Objectives

- To create a personal portfolio website.
- To demonstrate my knowledge of HTML and CSS.
- To showcase my technical skills and projects.
- To provide contact information through a contact page.
- To practise uploading and managing projects using GitHub.

Website Pages

The website consists of the following pages:

1. Home – Introduces me and displays my profile picture.
2. About Me – Provides information about my background and education.
3. Skills – Displays my technical skills.
4. Projects – Showcases my academic and personal projects.
5. Contact – Provides my contact information and a contact form.

Technologies Used

- HTML5 – For creating the website structure.
- CSS3 – For styling and designing the website.
- GitHub – For hosting and managing the project.
- GitHub Pages – For publishing the website online.

Features

- Multiple linked web pages.
- Personal profile picture.
- Navigation menu.
- External CSS stylesheet.
- Responsive website design.
- Images, hyperlinks, lists and forms.
